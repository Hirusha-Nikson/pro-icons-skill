Install

Pick where you use Claude. You only need one of these.

  1. In the Claude Code chat box, type /plugins (with an s) and press Enter. The Manage plugins dialog opens.
  2. Go to the Marketplaces tab, enter Hirusha-Nikson/pro-icons-skill and add it. It shows up as pro-icons.
  3. Switch to the Plugins tab, find Dev Icons (dev-icons) and click Install.
  4. Choose the scope that installs it for you in all your projects, not Install locally, which only covers the current repository.

Or open the install screen in VS Code

Start a new conversation afterwards. The skill appears as dev-icons:dev-icons.

  1. Turn on Code execution and file creation in claude.ai Settings.
  2. Download dev-icons.zip from the latest release.
  3. Go to Settings → Capabilities → Skills, click Upload skill and choose the zip.
  4. Make sure the skill is switched on, then start a new chat.

Download dev-icons.zip

In a Claude Code session:

/plugin marketplace add Hirusha-Nikson/pro-icons-skill
/plugin install dev-icons@pro-icons

Or from your shell:

claude plugin marketplace add Hirusha-Nikson/pro-icons-skill
claude plugin install dev-icons@pro-icons

To get later versions, run /plugin marketplace update pro-icons.

What to ask Claude

Ask in plain language. Claude looks up the icons, runs the right script and gives you the file.

README bannerMake a tech stack banner for my README: React, TypeScript, Node and Postgres.
SlidesI need Docker, Kubernetes and Terraform logos as PNGs for my slides.
Video introCreate an animated intro showing Python, FastAPI and Redis for my video.
PortfolioAdd a skills section with my stack to my portfolio site, using light tiles.

Good to know

Missing a logo?

Some brands asked Simple Icons to remove their logos, so these aren't included: AWS, Azure, DynamoDB, VS Code, Windows, C#, PowerShell, Playwright, Heroku, Slack and OpenAI. Claude tells you when an icon isn't available instead of drawing a substitute.

Request a logo (it has to exist on simpleicons.org).
